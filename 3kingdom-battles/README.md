# 三國・名戰錄

立體 3D 回合制攻守城戰。每一關是一場真實的三國戰役（野戰＋攻守城），可以選攻方或守方，對手是電腦。戰前有背景、兵力、勝利條件與攻城說明；戰後揭曉史實經過，看你是「尊重歷史」還是「逆轉歷史」。

目前可玩：**第 1 關 下邳之戰（198 年）**、**第 2 關 合肥之戰（215 年）**。第 3 關樊城之戰製作中（選關畫面可先看簡介）。

## 玩法重點
- **行動順序**：每回合所有部隊依速度排隊、敵我交錯行動（騎兵快、器械慢）。輪到己方時可以改派本回合還沒動的其他己方部隊先動（`RULES.chooseActive`），也可以「結束本回合」讓其餘部隊待命。輪到時可移動一次、做一個動作，沒有攻擊的話最後要選朝向（器械不用）。
- **射箭**：步兵、騎兵可向 2 格外放箭（`RULES.shootTargets`；威力為兵種攻擊的 0.18（步）／0.22（騎）倍，不吃兵種相剋、不被反擊）；呂布「騎射」0.6 倍、射程 3。
- **技能冷卻與代價**：主動技能用完有冷卻（`SKILLS[].cd`，按鈕顯示剩餘回合）；飛將、突襲另有 `cost`（陣勢 −12 × 統率係數 `steady`，陣勢 < 40 不能用）。
- **救援合流**：一方兵力 ≤ 35% 時可與相鄰友軍合為一支（`RULES` 的 `merge`）：兵力相加、士氣 +10，主帥（或統率較高者）統領，位置取兵力較多那格；併入的部隊不算陣亡、這回合不再行動。
- **同格**：一格最多兩支部隊，限器械＋一支友軍（`RULES.canStop`）；同格的器械受掩護，要先打掉作戰部隊。
- **方向**：被打的那一面決定傷害倍率（正面×1.0、前側×1.2、後側×1.4、背面×1.6，再依陣型調整）。受攻擊那面旁邊有友軍時，會「協防」降低加成。
- **陣型**：鋒矢、魚鱗、鶴翼、雁行、長蛇、方圓，各有攻擊倍率與四個方向的受傷倍率（數值在 `js/data.js` 的 `FORMATIONS`）。
- **陣勢**：側擊、背襲、衝鋒、合擊、被包圍會打亂陣型；動搖時陣型效果減半、混亂時失效，崩潰時依統率決定穩住／潰逃／就地解散。
- **包圍與合擊**：三面受敵或被前後夾擊算被包圍；夾擊時依統率與「合擊」技能加成。
- **攻城**：雲梯架梯才能攀城、衝車撞門、投石車打塌城牆、井闌掩護弓兵；守方有滾木礌石、火油、箭樓、出城突擊。
- **進出城**：只能走城門（守軍回城、出城都一樣）；攻方步兵要靠雲梯攀城，或等城門、城牆被打破。
- **下邳專屬**：第 6 回合起可在城北河堤掘堤水攻（大水可涉水、器械不能過，3 回合後退成泥濘）；城內士氣低落時侯成、宋憲、魏續可能倒戈開城；曹軍糧草耗盡就退兵；呂布軍可襲擾、火燒曹軍糧營（掎角之計）。
- **放火燒營**（`depotTargets`／`igniteDepot`／`burnDepot`）：地圖上的 `S` 是糧營；守方（非 `sc.depotOwner`）非器械部隊相鄰放火直接燒掉，或在射程內（弓兵 `rangeOf`、步騎 `shootRange`）射火箭（弓兵、呂布騎射 +2，步騎 +1，`vars.fire` 累積到 2 就燃）；燒掉後呼叫劇本的 `onDepotBurn`。
- **下邳的糧營與缺糧**：曹軍糧草分存在三座糧營（`vars.depots`，各有 `s`）；燒掉糧營：糧草 −`s`、曹軍士氣 −4；2 格內有守方部隊每回合騷擾（−1）；糧草 ≤ 0 就缺糧：曹軍每回合士氣 −8、陣勢 −3，滿 `starveLimit`（3）天退兵。
- **主將殺出重圍**：劇本設 `leaderEscape: true` 時，主將部隊第一次被打光，若 3 格內有友軍或人在城內，帶殘部（約 1.2%）傳送到友軍旁（`leaderEscape()`），第二次才被擒。下邳啟用、合肥沒有（晨襲擒孫權是設計好的結局）。
- **合肥專屬**：第 1 回合魏軍先動、吳軍陣型鬆散（張遼晨襲）；張遼「遼來」；魏軍衝進吳軍大營會放火；第 4 回合起吳軍疫病，第 9 回合或兵力折損過半撤軍；撤軍 2 回合後逍遙津橋被拆，只有孫權能躍馬跳過，孫權退到東邊撤退區即結束（史實），孫權被擊潰則生擒（逆轉）。
- **劇本設定**（`js/data.js` 的 `SCENARIOS`）：`sides[].tone` 陣營色調、`genMod` 劇本專屬武將能力、`hp` 城防耐久、`escape` 撤退區；專屬規則在 `js/rules.js` 的 `SC_RULES`，AI 目標在 `js/ai.js` 的 `hefeiGoal`／`xiapiGoal`。

## 存檔
- **自動存檔**：每次輪到玩家部隊時自動存檔；選關畫面「▶ 繼續上次戰役」接著打。戰役結束後清掉。
- **手動存檔**：☰ 選單「💾 儲存」有 3 個位置；「📂 讀取存檔」可讀回自動存檔或任一手動存檔。
- 存在瀏覽器 localStorage（`3kb-saves`）。規則層 `RULES.serialize(g)`／`RULES.restore(o)` 把局面轉成純資料；亂數狀態 `g.rs` 一起存，讀檔後接著打的結果與沒存檔時相同。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html`、`css/style.css` | 頁面與樣式（手機直式為主，寬螢幕面板在右側） |
| `js/hex.js` | 六角格座標（奇數列右移）、距離、方向 |
| `js/data.js` | 地形、兵種、陣型、技能、武將、戰役劇本與文字（**調整平衡主要改這裡**） |
| `js/rules.js` | 規則（不碰畫面）：移動、控制區、傷害、方向、合擊、陣勢崩潰、攻城、回合結算、下邳事件、勝負與結局 |
| `js/ai.js` | 電腦：每支部隊列出可到達位置 × 動作打分（戰果 − 風險 + 往目標的路程） |
| `js/render3d.js` | Three.js 3D 畫面：連續地表（`buildGround`／`paintGround`：高度依六角格平滑過渡，顏色畫在一張貼圖上再疊色塊、筆觸、淡格線；點選用 `hexAtWorld` 換回六角格）、城池（直向城牆在畫面上對齊成直線 `computeSnap`，`buildWalls` 畫連續城垣；規則仍是六角格）、擺設 `buildProps`（火把、河岸石頭、糧營木柵／哨塔／拒馬）、草叢與灌木、部隊（圓形頭像徽章）、方向弱點圈、動畫 |
| `js/portraits.js` | 武將頭像：依《三國演義》外貌描寫用 SVG 繪製（`LOOKS`），以及演義中寫到的情緒（`MOODS`，附原文與回數）；戰前說明「登場武將」、部隊資訊、事件、單挑／技能特寫與結局會用到 |
| `assets/portraits/` | 頭像美術規範 `ART_GUIDE.md`、人物清單與生成模板 `characters.js`、生成紀錄 `log.json`、提示詞 `prompts/`；PNG 審核通過後自動取代 SVG |
| `tools/portraits.js` | 頭像工具：`prompts` 產生提示詞、`import` 入庫並記錄、`check` 檢查對應與規格、`sheet` 縮小辨識度對照表、`gen` 直接呼叫 OpenAI 圖片 API |
| `js/cavalry.js` | 騎兵模型：披甲戰馬＋騎士的小零件合併成 `coat`（毛色，instanceColor）與 `gear`（馬衣、甲、騎士，頂點色）兩個幾何體，站立／奔馳兩種姿態；名馬毛色在 `SIGNATURE`。用到 `BufferGeometry`，所以 `vendor/three.min.js` 要用 `tools/build_three.sh` 重新打包（腳本會同時掃 render3d.js 與 cavalry.js） |
| `js/scenes.js` | 插圖：用 SVG 程式繪製的水墨風場景（遠山、霧、河、城樓、營帳、軍隊、騎兵、火、大水、斷橋……）。`EVENT` 把事件標題對到場景，結局用 `劇本:結局` 當鍵；新增事件或結局時記得加一張 |
| `js/ui.js`、`js/main.js` | 選關、戰前說明、戰場操作面板、結局 |
| `js/version.js`、`tools/bump_version.py` | 版本號；改版時執行 `python3 3kingdom-battles/tools/bump_version.py 2026-xx-xx.nn` |
| `js/changelog.js`、`js/update.js` | 更新內容（**每次改版在 `CHANGELOG` 最上面加一筆**）與新版本通知：有新版時下方跳出「🆕 有新版本，點此更新」，改版後第一次開啟自動彈出新內容 |
| `vendor/three.min.js` | 只打包用到的 Three.js 類別；`render3d.js` 用到的類別有增減時執行 `bash 3kingdom-battles/tools/build_three.sh` |
| `tools/sim.js` | AI 對 AI 模擬：`node 3kingdom-battles/tools/sim.js 30 v hefei` 看勝負分布（第 3 個參數是劇本，預設 xiapi；調平衡用） |
| `tests/` | 自動化測試 |

## 測試
```bash
npm i playwright                          # 第一次
node 3kingdom-battles/tests/run.js        # 全部（規則 21 項＋頭像 2 項＋介面 14 項）
node 3kingdom-battles/tests/run.js 攻城   # 名稱含「攻城」的
```
網址參數：`?sc=xiapi&side=att|def` 直接開戰、`&seed=數字` 固定亂數、`&speed=2` 動畫速度、`&auto` 雙方都由電腦操作、`&fast` 跳過動畫。
