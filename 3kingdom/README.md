# 三國・攻城守城

回合制戰略小遊戲：魏、蜀、吳三國爭霸。在地圖上派兵行軍，兵臨城下後進入**攻城戰**——攻方與守方同時選戰術，像猜拳一樣互相剋制。攻下其他兩國的都城即一統天下。

## 玩法摘要
- 每回合：點自己的城 → 選相鄰城池「出兵」（拉桿決定兵力）；可花金幣徵兵、修城牆 → 按「結束回合」。
- 行軍：軍隊沿道路走，路遠要多回合；對向相遇會野戰；抵達敵城／中立城就開始圍城。
- 攻城（每回合一輪）：攻方 衝車／雲梯／火攻／圍困，守方 固守／箭雨／出城／潑水，依克制表（`js/data.js` 的 `MATRIX`）結算；攻方統率、守將智力會影響效果。城牆破或守軍殲滅時決戰，攻方贏就攻陷。
- 都城陷落＝該國滅亡。

詳細設計與之後的開發方向見 [GAME.md](GAME.md)。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html`、`css/style.css` | 頁面與樣式 |
| `js/data.js` | 靜態資料：城池、道路、武將、攻守戰術、克制表（**調整平衡主要改這裡**） |
| `js/game.js` | 規則（不碰畫面）：出兵、行軍、野戰、圍城結算、佔領、結算、勝負 |
| `js/ai.js` | 電腦：出兵與攻守戰術 |
| `js/turn.js` | 回合流程；`hooks` 讓畫面層插入動畫與選戰術 |
| `js/render.js`、`js/ui.js`、`js/main.js` | 地圖與攻城場景繪圖、面板與彈窗、啟動 |
| `js/version.js`、`tools/bump_version.py` | 版本號；改版時執行 `python3 tools/bump_version.py 2026-xx-xx.nn` |
| `tests/` | 自動化測試 |

## 測試
```bash
npm i playwright          # 第一次
node 3kingdom/tests/run.js            # 全部（規則 10 項＋介面 10 項）
node 3kingdom/tests/run.js 攻城       # 名稱含「攻城」的
```
網址參數：`?faction=shu|wei|wu` 直接開局、`&seed=數字` 固定亂數種子。
