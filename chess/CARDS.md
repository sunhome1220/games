# 強化卡牌：增減與維護

強化卡牌全部寫在一份資料表 `CARDS`（`chess/js/cards.js`，搜尋「強化卡牌清單」即可找到）。
選牌畫面、棋盤下方的「🃏 我的強化」清單、更新提示都是從這份表自動產生，**增減卡牌只要改這一處**。

## 一張卡長這樣

```js
{ id: 'r_dmg', ic: '🔫', name: '俥・加裝彈鏈', need: 'R', max: 3, fx: { R: { dmg: 0.5 } } },
```

| 欄位 | 說明 |
|---|---|
| `id` | 唯一代號（不可重複） |
| `ic` | 圖示（一個 emoji） |
| `name` | 名稱（「兵種・名稱」格式，棋盤下方的摘要會取後半） |
| `tier` | 選填。等級：`1` 普通（預設）、`2` 稀有、`3` 瘋狂、`4` 終極魔法（見下方「等級與出現機率」） |
| `fx` | 效果（加強**己方**）：`{ 兵種代號: { 數值名: 增減量 } }`，可同時加強多個兵種；`allFx('dmg', 1)` 可一次套用到全軍 |
| `foe` | 選填。效果（削弱**敵方**），格式同 `fx`，數值通常是負數（例：`foe: allFx('dmg', -0.5)`）。有 `foe` 的卡必須自己寫 `desc` |
| `max` | 同一方最多可拿幾張。目前 `CARD_STACK = false`：不論 `max` 為何，每張卡每方只能拿一次；把 `CARD_STACK` 改成 `true` 即恢復依 `max` 疊加 |
| `need` | 選填。己方場上還有這種棋子才會出現（`K R N C E G P`） |
| `cond` | 選填。額外條件，函式 `side => 布林`（例如「冷卻大於 0 才有意義」） |
| `desc` | 選填。說明文字；**省略時會由 `fx` 自動產生**（例如「俥 威力 +0.5 心」） |
| `instant` | 選填。立即效果的函式 `side => {…}`（急救、補給這類不改數值的卡） |
| `off` | 選填。設為 `true` 暫時停用這張卡 |

### 兵種代號
`K` 帥、`R` 俥、`N` 傌、`C` 炮、`E` 象、`G` 仕、`P` 兵、`P2` 士官長（過河後的兵）

### 數值名
| 名稱 | 單位 | 說明 |
|---|---|---|
| `dmg` | 心 | 威力 |
| `range` | `C` 的倍數（格） | 射程，例：`1.5 * C` = 1.5 格 |
| `min` | `C` 的倍數 | 最小距離 |
| `splash` | `C` 的倍數 | 波及範圍 |
| `aa` | `C` 的倍數 | 象的防空範圍 |
| `hp` | 心 | 血量上限（拿到時同時回復同樣的量） |
| `reload` | 回合 | 冷卻（負數＝縮短，最低到 0） |
| `healAmt` | 心 | 象每回合開始替 2.5 格內受傷最重的友軍回復的量 |
| `armor` | 心 | 減傷：每次受傷少受這麼多，至少仍受 ¼ 心（神之護盾期間完全免疫） |

敵方減益有下限，避免玩不下去：威力 ¼ 心、射程 1 格、血量上限 1 心、防空範圍 ½ 格、冷卻 0（見 `buildTypes`）。

需要新增「數值名」時：在 `STAT_INFO`（說明與格式）加一筆，並確認程式會讀取該欄位。

## 常見操作

- **新增卡牌**：在 `CARDS` 加一筆。例：`{ id: 'c_dmg2', ic: '☄️', name: '炮・重型彈頭', need: 'C', max: 2, fx: { C: { dmg: 1 } } }`
- **停用卡牌**：該筆加上 `off: true`。
- **刪除卡牌**：直接移除該筆。（進行中的對局若已有人拿過，該卡會從清單中略過，不會出錯。）
- **調整數值**：改 `fx` 內的增減量或 `max`；說明若是自動產生的就不用另外改。

## 防呆

遊戲載入時會逐張檢查卡牌表：缺欄位、`id` 重複、未知的兵種代號或數值名、沒有效果的卡，都會被**忽略並在瀏覽器主控台警告**
（`[強化卡牌] 已忽略：…`），不會讓整個遊戲壞掉。

## 其他規則（寫在程式別處）

- 時機：開局雙方各選一張，之後每方自己的第 N、2N、3N… 個回合開始前再選一張（N 見「選牌間隔」，預設 10）；選牌時三選一。
- 強化存放在每方一份的兵種數值表 `TT[side]`，所有規則直接讀取，所以電腦對戰與連線同步都會生效。
- 開始畫面（對戰模式選單）可開關；連線時以房主設定為準。

## 等級與出現機率

選牌時，依「這一方已經選過幾張」決定各等級的機率（`TIER_WEIGHTS`，可自行調整）：

| 已選張數 | ★ 普通 | ★★ 稀有 | ★★★ 瘋狂 | ✨ 終極魔法 |
|---|---|---|---|---|
| 0（開局） | 100% | | | |
| 1 | 60% | 40% | | |
| 2 | 30% | 50% | 20% | |
| 3 | 10% | 40% | 40% | 10% |
| 4 以上 | | 20% | 50% | 30% |

某個等級沒牌可抽時，會改從現有的等級平均抽。一次三選一最多出現一張終極魔法。

## 終極魔法（`tier: 4`，用 `instant`）

隕石雨、起死回生、時間暫停、神之護盾、天雷審判、冰封世界都寫在 `CARDS` 裡（`ult_*`）。寫新的終極魔法時：
- 用 `spellHit(棋子, 傷害, 延遲秒數, 是否不致死)` 造成法術傷害（無視減傷、神之護盾擋得住）；`bigText('文字', '#顏色')` 在棋盤中央顯示招式名稱。
- 效果必須是**固定的**（不能用亂數），因為連線時兩台裝置都會各執行一次。
- 需要「場上要有某種狀態才有意義」的，用 `cond` 控制是否出現（例：起死回生要有陣亡的棋子）。
- 需要跨回合記住的狀態（護盾 `immune`、額外回合 `extraTurn`）要放進局面快照（`network.js` 的 `snapshot()`／`applySnap()`）。

## 選牌間隔

開始畫面「🃏 強化卡牌設定」可選每 3／5／8／10／15／20 回合選一次（`cardEvery`，記在瀏覽器；連線時房主的設定會在連線時傳給對方）。
