# 強化卡牌：增減與維護

強化卡牌全部寫在一份資料表 `CARDS`（`chess/js/cards.js`，搜尋「強化卡牌清單」即可找到）。
選牌畫面、棋盤下方的「🃏 我的強化」清單、更新提示都是從這份表自動產生，**增減卡牌只要改這一處**。

## 一張卡長這樣

```js
{ id: 'r_dmg', ic: '🔫', name: '俥・加裝彈鏈', need: 'R', max: 3, fx: { R: { dmg: 0.5 } } },
```

| 欄位 | 說明 |
|---|---|
| `id` | 唯一代號（不可重複） |
| `ic` | 圖示（一個 emoji） |
| `name` | 名稱（「兵種・名稱」格式，棋盤下方的摘要會取後半） |
| `fx` | 效果：`{ 兵種代號: { 數值名: 增減量 } }`，可同時加強多個兵種 |
| `max` | 同一方最多可拿幾張。目前 `CARD_STACK = false`：不論 `max` 為何，每張卡每方只能拿一次；把 `CARD_STACK` 改成 `true` 即恢復依 `max` 疊加 |
| `need` | 選填。己方場上還有這種棋子才會出現（`K R N C E G P`） |
| `cond` | 選填。額外條件，函式 `side => 布林`（例如「冷卻大於 0 才有意義」） |
| `desc` | 選填。說明文字；**省略時會由 `fx` 自動產生**（例如「俥 威力 +0.5 心」） |
| `instant` | 選填。立即效果的函式 `side => {…}`（急救、補給這類不改數值的卡） |
| `off` | 選填。設為 `true` 暫時停用這張卡 |

### 兵種代號
`K` 帥、`R` 俥、`N` 傌、`C` 炮、`E` 象、`G` 仕、`P` 兵、`P2` 士官長（過河後的兵）

### 數值名
| 名稱 | 單位 | 說明 |
|---|---|---|
| `dmg` | 心 | 威力 |
| `range` | `C` 的倍數（格） | 射程，例：`1.5 * C` = 1.5 格 |
| `min` | `C` 的倍數 | 最小距離 |
| `splash` | `C` 的倍數 | 波及範圍 |
| `aa` | `C` 的倍數 | 象的防空範圍 |
| `hp` | 心 | 血量上限（拿到時同時回復同樣的量） |
| `reload` | 回合 | 冷卻（負數＝縮短，最低到 0） |
| `healAmt` | 心 | 象每回合開始替 2.5 格內友軍回復的量 |

需要新增「數值名」時：在 `STAT_INFO`（說明與格式）加一筆，並確認程式會讀取該欄位。

## 常見操作

- **新增卡牌**：在 `CARDS` 加一筆。例：`{ id: 'c_dmg2', ic: '☄️', name: '炮・重型彈頭', need: 'C', max: 2, fx: { C: { dmg: 1 } } }`
- **停用卡牌**：該筆加上 `off: true`。
- **刪除卡牌**：直接移除該筆。（進行中的對局若已有人拿過，該卡會從清單中略過，不會出錯。）
- **調整數值**：改 `fx` 內的增減量或 `max`；說明若是自動產生的就不用另外改。

## 防呆

遊戲載入時會逐張檢查卡牌表：缺欄位、`id` 重複、未知的兵種代號或數值名、沒有效果的卡，都會被**忽略並在瀏覽器主控台警告**
（`[強化卡牌] 已忽略：…`），不會讓整個遊戲壞掉。

## 其他規則（寫在程式別處）

- 時機：開局雙方各選一張，之後每方自己的第 10、20、30… 個回合開始前再選一張；選牌時三選一。
- 強化存放在每方一份的兵種數值表 `TT[side]`，所有規則直接讀取，所以電腦對戰與連線同步都會生效。
- 開始畫面（對戰模式選單）可開關；連線時以房主設定為準。
