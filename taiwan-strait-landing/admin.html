管理者設定

替「台海兵棋推演」的管理者開關算出密碼雜湊、產生 status.json 的內容。所有計算都在你的瀏覽器裡完成，密碼不會傳到任何地方。

1. 設定管理者密碼

密碼只有你知道，倉庫裡只存雜湊。隨機密碼請存進密碼管理員；忘記了就重新設定一組（換掉雜湊即可）。

2. 開放或關閉

3. 貼到 status.json

開啟 GitHub 編輯 status.json
  1. 按「複製」。
  2. 按「開啟 GitHub 編輯」，全選舊內容、貼上新內容。
  3. 按右上「Commit changes…」，直接 commit 到 main。
  4. 約 1～2 分鐘後生效。

如果選「對外關閉」，請先確認上面已設定管理者密碼，否則連你自己也進不去。

4. 管理者登入網址

關閉期間用這個網址進入（只需一次，這台裝置會記住）：

先輸入密碼

登出：在網址後加 ?admin=logout。把登入網址存在你自己的記事本，不要分享給別人。

限制

  • 這是軟性關閉：程式碼是公開的，擋得住一般訪客，擋不住會自己下載程式碼的人。
  • 要立刻、完全下線：GitHub 倉庫 Settings → Pages → Unpublish site，或把倉庫改為私人。
