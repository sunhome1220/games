# 存檔

- 自動存檔：每次輪到人類操作的階段開始時（`beginPhase` 結尾）存一份；電腦先推演期間、電腦推演模式、影片模式、關卡挑戰不存。
- 手動存檔：設定頁（首頁的設定或遊戲內 ⚙）有 3 個存檔位，可存入／讀取／刪除；首頁在有自動存檔時出現「繼續上次戰局」。
- 內容：`S`（去掉選取、模式等畫面暫存）、亂數位置 `RNGA`、小數累計 `ACC`、日誌序號 `LOGN`、設定選項。讀檔後接著同一條亂數序列，結果與不中斷相同（測試比對）。
- 相容性：`SAVE_VER` 是存檔格式版本，與畫面上的遊戲版本分開。畫面、文字、一般規則的小改版舊存檔照讀，新增欄位以預設值補上（`newState()` 的預設值）；只有 `S` 結構不相容時才把 `SAVE_VER` 加 1，舊存檔會提示讀不了。
- 限制：存在這個瀏覽器的 localStorage（清除網站資料會消失）；戰後影片的回放紀錄不存，讀檔後只錄得到之後的部分。
